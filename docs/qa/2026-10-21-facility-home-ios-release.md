# 현황판·예약자 홈·iOS 2.2.3 반영 기록

## 변경 범위

- 관리자 대시보드와 예약자 홈에 공유 공간·장비 현황판을 연결했다. 제공된 복도 배치의 상대 위치와 예약 대상 다섯 곳을 보존하고, 평면도·시간표·장비 반출 상태를 제공한다.
- 서버에서 역할별 응답을 분리해 예약자에게 타인의 개인정보를 제공하지 않는다. 조회 실패·오래된 자료·실제 반출과 예약 예정을 구분한다.
- 모바일에서 다섯 공간 요약이 모두 보이도록 정리하고, 주요 조작을 접근성 이름이 있는 44px 아이콘 버튼으로 표시한다.
- 예약자 홈은 내 예약 최대 2건과 현황판을 중심으로 줄였다. 보고서는 작성 가능한 항목이 있을 때, 공지는 한 줄만 표시한다. 즐겨찾기와 다시 예약은 새 예약 화면에 배치한다.
- iOS 및 Android 버전 메타데이터는 2.2.3 (45)로 정렬했다. iOS 앱에 최신 웹 자산을 동기화해 App Store Connect로 업로드했다. Android 스토어 배포는 수행하지 않았다.

## 검증 및 배포 기록

- 2026-10-19 전체 `npm run release:check` 통과: UI 175건 통과, 29건 조건부 생략, 실패·재시도 없음. 별도 WebKit 홈·즐겨찾기·다시 예약 검사도 통과했다.
- Worker `4e5b3f72-f601-4580-a8cc-d316dfeadda2`, Pages `50f0d098-3cd8-4f0e-b656-f1259e5ac928`로 운영 배포했다. 두 주소의 자산 해시·API 버전·인증 가드와 Chromium·WebKit HTTPS 로딩을 확인했다. 웹 진입 자산 식별자는 `20261019-facility-r4`다.
- 2026-10-20 iOS 26.5 / iPhone 17 Pro 시뮬레이터에서 2.2.3 (45) 빌드·설치·실행을 확인했다. Release 아카이브의 서명과 네이티브 자산 43개의 해시도 검증했다.
- App Store Connect 앱 `6784429269`의 빌드 `73eacc7b-773e-48df-8a64-b619625621e2`를 2.2.3 버전에 연결하고 업데이트 설명·심사 메모를 저장했다. 2026-10-20 심사 제출 후 `심사 대기 중`과 승인 후 자동 출시 설정을 확인했다. 이 문서는 당시 확인 기록이며 이후 심사 상태는 별도 확인이 필요하다.
- 역할별 예약 조작은 격리된 로컬 API에서 확인했다. 운영 예약 생성·수정과 실제 iPhone에서의 네이티브 예약 동작은 이번 검증에 포함하지 않았다.
