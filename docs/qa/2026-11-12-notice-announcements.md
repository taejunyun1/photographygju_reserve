# 공지 알림 및 읽음 상태 — 2026-11-12

- 학생에게 미확인 공지를 제목·아이콘 중심의 토스트로 표시한다. 고정 공지 우선, 최신 공지 순서로 한 건씩 표시하고 미확인 건수를 함께 제공한다. 공지를 누르면 해당 공지 상세가 열린다.
- 공지 목록과 홈에서 열어도 같은 읽음 처리를 사용한다. 읽음 상태는 인증된 학생의 사용자 데이터에 저장하며 기기 저장소만으로 판단하지 않는다. 일반 사용자 응답에는 읽음 이력을 노출하지 않는다.
- 로그인·앱 복귀·새로고침에서 상태를 불러온다. 사용 중에는 화면 복귀 및 60초 간격으로 공지만 조용히 갱신한다. 숨김 공지는 대상에서 제외한다.
- 예약·보고서 작성 중, 공지 상세를 열었을 때, 다른 상태 토스트 표시 중에는 공지 토스트를 표시하지 않는다. 모바일 메뉴와 안전 영역을 피하고 44px 이상의 조작 영역을 제공한다.
- 읽음 저장 실패는 성공으로 처리하지 않는다. 늦게 도착한 계정 A의 응답이 계정 B에 적용되지 않으며, 갱신 도중 저장한 읽음 상태를 이전 응답으로 되돌리지 않는다.
- `GET /api/me/notices`는 본인의 활성 공지와 읽음 상태를, `POST /api/me/notices/:id/read`는 본인의 읽음 저장을 담당한다. 인증된 학생의 ID만 사용하며 요청 본문으로 다른 계정을 지정할 수 없다.
