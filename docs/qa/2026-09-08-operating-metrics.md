# 운영 지표 기준 (2026-09-08)

- 이번 주 예약 수: 한국시간 월요일부터 일요일까지 예약 시작일 기준, 취소·관리자 취소·반려 제외. 미래의 이번 주 예약은 포함한다.
- 현재 대여 가능 비율: 활성 등록 장비 중 상태가 가능이고 예약 허용이며 문의 전용이 아닌 장비에서 현재 점유된 장비를 제외한다. 점유는 미반납 대여 전체(연체 포함), 현재 시간과 겹치는 승인·승인대기 예약이다. 미래 예약과 취소는 현재 점유가 아니다. 장비 ID는 중복 없이 센다.
- 전체 활성 등록 장비를 분모로 유지한다. 현재 가능, 예약·대여 중, 설정상 제한의 합은 활성 등록 수다. 이는 특정 미래 기간에 대한 예약 가능 여부를 보장하지 않는다.
- 수리중 기자재: 활성 장비 중 수리중 상태. 설정상 제한 장비에도 포함된다.
- 취소·반려 / 예약 유형 / 인기 장비: 오늘 포함 최근 28일 예약 시작일 기준. 기간을 벗어나는 과거·미래 예약을 제외한다. 유형·인기 장비는 취소·반려를 제외한다.
- 보고서 확인 큐: 제출된 보고서 중 미확인. 미제출 보고서 수와 별도다.
- 모집중 특강: 관리자가 모집중으로 설정한 특강 수.

인사이트의 취소율은 접수일 기준이며 본 운영 지표는 예약일 기준이므로 서로 다른 집계임을 화면에 명시한다.
