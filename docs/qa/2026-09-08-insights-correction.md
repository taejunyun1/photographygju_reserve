# 운영 인사이트 집계 수정 (2026-09-08)

9월 3일 배포의 점유율 분모는 예약 건수와 장비 수를 비교해 의미가 없었다. 이 문서는 기존 점유율 설명을 대체한다.

- 예약 많은 시간: 최근 28일 예약일 기준 취소·반려를 제외한 시간대별 예약 건수. 동일 예약의 중복 시간대는 한 번만 센다. 동일 유형·시간대가 3건 이상일 때만 표시하며 실시간 혼잡도나 수용량 대비 점유율로 해석하지 않는다.
- 장비 예약일 비율: 승인 대기·승인·대여·반납 등 유효 예약이 차지하는 달력 일수 / 28일. 대여 시작일과 반납일을 포함하며 기간 밖 날짜와 겹친 날짜는 제외한다. 실사용 시간이 아니다.
- 취소율 (반려 포함): 기간 내 접수된 요청 중 취소·관리자 취소·반려 비율. 5건 미만이면 숨기며 20건 미만이면 참고용 표본 안내를 표시한다.
- 화면에 집계 시작일·종료일을 표시한다. 관리자 번들의 URL 버전을 변경해 이전 번들의 캐시 재사용을 방지한다.

회귀 검증: 단건 예약 추세 제외, 3건부터 표시, 잘못된 수용량 분모 제거, 집계 시작일 이전의 장기 대여 포함, 중복 날짜·취소 제외. 반응형 관리자 화면에서 카드 문구와 높이, 이동 필터를 검사한다.
