# 디지털사진영상실 복도 평면도 QA

사용자는 디지털사진영상실도 기존 복도 평면도에 표시하도록 정정했고, 실제 위치를 **스튜디오 B의 왼쪽**으로 확정했다.

## 변경

- 아래쪽 빈 방 x730·너비200을 디지털사진영상실로 표시한다. 스튜디오 B의 x930 경계와 맞닿으며 기존 다섯 방과 계단 위치는 유지한다.
- 6번 번호, 컴퓨터 아이콘, Mac·PC 가용 좌석 수, 예약·이용 제한 상태를 표시한다. 모바일 기본 축소 지도는 다른 방처럼 번호를 사용한다.
- 지도와 여섯 번째 공간 요약 버튼에서 같은 예약 상세를 열고 선택 상태를 공유한다. 기존 16석 현황판과 예약 진입을 유지한다.
- 키보드 이동은 표시되는 방 수를 사용하며, 디지털실이 없는 이전 응답은 기존 다섯 개 방으로 동작한다.
- 태블릿에서 긴 실명이 잘리는 문제를 확인해 디지털실 제목만 줄바꿈을 허용했다.
- React JS/CSS 네 개 URL의 release를 `20261111-lab-corridor-r1`로 갱신한다. 서버·예약 정책·저장 구조·운영 설정은 변경하지 않는다.
