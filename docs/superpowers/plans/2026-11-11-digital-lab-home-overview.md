# 메인 디지털사진영상실 좌석 현황판

사용자 확정: 메인화면에서 Mac 12석·PC 4석을 펼쳐진 좌석 현황판으로 본다. 현재 브랜치와 기존 예약 정책을 유지하고 웹 배포까지 반영한다.

- [x] 기존 가용 수 요약 줄을 16석 현황 영역으로 확장한다. 기존 조회 날짜·시간의 예약/차단 데이터를 재사용하며 색과 문구로 상태를 표시한다. 복도 도면 좌표는 변경하지 않는다.
- [x] 예약 내역 열기와 좌석 예약 진입을 제공한다. 분 단위 조회 시각을 유효한 예약 시간으로 간주하지 않고 기존 예약 화면에서 다시 선택하게 한다. 기존 상세 영역의 좌석 중복 표시는 제거한다.
- [x] 실제 격리 API로 메인 좌석 표시·시간 변경·예약 화면 진입을 검증하고, 320–1440px 배치와 기존 현황판 동작을 확인한다. 변경된 React JS/CSS의 release 값을 갱신한다.
- [x] Worker/Pages를 기존 변수와 데이터 보존 조건으로 배포한다. 공개 자산 해시·버전·운영 설정을 확인하고 QA에 기록한다. 운영 시험 예약, GitHub push, 네이티브 패키지 생성은 수행하지 않는다.

검증 범위: 타입/렌더, 현황판 통합, 학생 예약 UI, 모바일 및 데스크톱 실제 브라우저. 서버 예약 판정과 저장 구조는 변경하지 않는다.
